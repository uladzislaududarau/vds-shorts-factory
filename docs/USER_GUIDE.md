# Руководство

Запустите `start.command`. Обзор показывает реальные counts, очередь, движок и свободное место. Светлая/тёмная тема переключается внизу навигации.

**YouTube.** Добавить видео → YouTube. Нажмите «Войти в YouTube», войдите в отдельном Chrome и вернитесь к «Я вошёл — подключить». Вставьте URL, оставьте включёнными скачивание и автоматический поиск моментов, подтвердите основание прав и нажмите «Скачать и анализировать». Ход загрузки и следующие этапы видны в очереди. Аккаунтом также можно управлять в Settings → YouTube. [Подробное руководство](YOUTUBE.md).

**Исходники.** Перетащите файлы на импорт или выберите папку с абсолютным путём. Укажите права и основание, подтвердите обработку. Видео копируются в `data/sources`; SHA-256 предотвращает повторный импорт. Убрать из библиотеки — архивирование, оригинал остаётся.

**Анализ.** Поставьте в очередь 1–100 видео. Задайте минимальную/максимальную длину, количество 3/5/10/20/Auto, threshold, профиль и язык. Количество — максимум; слабые моменты не добавляются ради заполнения. Для облака сохраните ключ и модель, разрешите cloud, подтвердите конкретную отправку в диалоге анализа. Можно оставить согласие выключенным для local. Первое скачивание модели не отправляет запись или текст.

**Анализ видео.** Оригинальный плеер, сцены и кандидаты на timeline. Щелчок по строке транскрипции или таймкоду кандидата переводит плеер. Раскройте оценки, прочитайте предупреждения, проверьте контекст. Отметьте одобрение. Ручной фрагмент можно создать без анализа, указав начало/конец. Без распознанных слов субтитры надо явно выключить перед рендером.

**Clip Studio.** Начало/конец вводятся числом или range handles. Добавьте сегменты для склейки; порядок отображения — порядок монтажа. Можно сократить паузы по словам. Crop: полный кадр на размытом фоне, центральный, трекинг лица, разделение левой/правой половин, ручной x/y. Выберите формат, FPS, звуковые фильтры, стиль подписи. В разделе субтитров можно исправить отдельные слова для этого клипа, сохранив реальные timestamps; исходная транскрипция и AI-анализ не меняются. Whisper иногда ошибается, поэтому проверяйте готовые подписи. Сохраните и нажмите Generate Reel. Смена стиля не вызывает AI повторно.

Preview исходника приблизительный. После рендера переключите на **готовый MP4** и посмотрите от начала до конца. Если есть новая ревизия, перерендерите: старый файл не считается автоматически обновлённым. MP4/SRT/ASS скачиваются в редакторе.

**Очередь.** Pause останавливает текущую стадию, Resume начинает её заново с кэшированными предыдущими результатами. Cancel сохраняет уже завершённые стадии, Retry запускает задачу снова. Ошибки и журнал доступны на каждой строке. После штатного stop работа приостанавливается; Resume после запуска. После аварийного закрытия Running восстанавливается в очередь.

**Библиотека.** Отметьте клипы → **Generate Reel** → задайте единые формат/FPS/кадрирование/стиль субтитров → **Создать и скачать ZIP**. Границы и сегменты каждого клипа сохраняются. Можно оставить индивидуальные настройки, выключив «Единые настройки». В Smart Face Crop отдельно выбирается поведение без лица: Center Crop без размытия либо размытый фон. Ролики создаются по очереди; после завершения всех появляется ZIP. При открытом приложении он скачивается автоматически, а постоянная ссылка доступна в очереди. За одну операцию — до 100 клипов. Для уже готовых выбранных клипов есть «Скачать ZIP».

**Отобранные.** Это ваша подборка, а не обязательное разрешение на генерацию. Выберите клипы и нажмите «В отобранные» либо значок закладки на карточке. Во вкладке «Отобранные» можно убрать их из подборки и генерировать тем же Generate Reel.

**Удаление клипов.** Отметьте ненужные → «Удалить» → проверьте список → «Удалить клипы». Удаляются записи, версии MP4, SRT/ASS и их монтажные планы. Исходное видео и уже созданные ZIP сохраняются. Отменить подтверждённое удаление нельзя. При незавершённой генерации/ZIP сначала дождитесь завершения или отмените задачи в очереди. Отмена в диалоге ничего не удаляет.

**Метаданные экспорта.** По умолчанию ZIP содержит только MP4; отдельные субтитры и внутренний JSON/CSV-отчёт добавляются только по вашему выбору. Из MP4 очищаются пользовательские теги, главы и название программного кодировщика. Технические поля контейнера/кодека сохраняются. Старые ролики также очищаются при выдаче, без изменения сохранённого оригинала. Это не гарантия сокрытия происхождения видео или отсутствия претензий платформы. [Подробности](EXPORT_AND_LIBRARY.md).

**Новая музыка и голос.** Библиотека → выбрать клипы → Generate Reel → «Звуковая дорожка». Доступны самостоятельная AI-музыка или музыка с переозвучкой распознанных слов выбранным голосом. Исходный звук, включая эффекты, полностью удаляется. На выходе готовые MP4/ZIP; новый сценарий не требуется. [Порядок работы и лимиты](AUDIO_REPLACEMENT.md).

**Где готовый файл.** Очередь → завершённая задача → «Показать в Finder»: открывается папка и выделяется файл именно этой задачи. Для готового рендера есть «Скачать MP4», для ZIP — скачивание архива. Под названием задачи показано имя файла; полный путь виден в подсказке. Рендеры сохраняются в `data/renders`, ZIP — в `data/exports`. Если файл удалён/перемещён, приложение не открывает вместо него другую версию.

**Настройки.** В «AI и модели» доступны Local, Gemini и OpenAI; в «Озвучка» — ElevenLabs API key, Voice ID, модель, лимиты голоса и отдельный блок Eleven Music. «AI-проба» остаётся отдельным экспериментом со сценарием. [Подключение API](AI_CONNECTIONS.md). Test connection не отправляет материал и не гарантирует поддержку мультимодального анализа выбранной моделью. Укажите реальные тарифы для оценочного USD-бюджета. В «Хранилище» можно очистить временные аудио/кадры/превью после остановки очереди, включая аудиопробы ElevenLabs. Оригиналы, AI-кэш, слова, проекты и клипы сохраняются.


## Публикация в YouTube

Настройки → Публикации: добавьте OAuth JSON Google, подключите канал и сохраните профиль. Библиотека → выберите готовые MP4 → В YouTube → Создать тексты и запланировать. Расписание — раз в час круглосуточно, время Кипра. Тексты создаёт OpenAI; лимит запросов и бюджет учитываются. Полная инструкция: [YOUTUBE_PUBLISHING.md](YOUTUBE_PUBLISHING.md).
