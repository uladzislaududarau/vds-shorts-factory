# Устранение ошибок

**Нет места.** Освободите место вручную или используйте Settings → Хранилище → Очистить временный кэш после отмены очереди. Студия не удаляет оригиналы автоматически. Reserve по умолчанию 512 МБ; рендер дополнительно оценивает до 3 МБ/с результата. Не снижайте запас до нуля.

**Whisper долго запускается.** Первый запуск скачивает модель. Сеть/Hugging Face могут быть недоступны. Ошибка видна в очереди; Retry использует сохранённый WAV. Веса Tiny экономят место, Base/Small точнее. Папка весов — `data/models/`. Нативный Metal проверяется `doctor.command`. Выполняйте приложение на Mac, не в контейнере.

**Нет хороших кандидатов.** Локальная эвристика не обещает смысловой интеллект. Уменьшите threshold, измените min/max, проверьте язык, выберите фрагмент вручную или подключите Gemini. Отсутствие кандидатов не заменяется равномерной нарезкой.

**Gemini не запускается.** Нужны key, provider=Gemini, доступная модель, global cloud toggle и per-job consent. Для USD-budget нужны реальные цены; при неизвестной цене запрос блокируется. Проверьте model permissions/квоту/поддержку structured video. 429/5xx повторяются с backoff до трёх раз. Не проверено без ключа.

**Видео YouTube недоступно.** Проверьте, открывается ли ролик в вашем аккаунте в отдельном окне Chrome студии. Подключите сессию в Settings → YouTube и скачивайте с включённым «Использовать мой аккаунт». При истёкшем входе нажмите «Обновить сессию». DRM и ограничения, действующие для самого аккаунта, вход не снимает. [Подключение и скачивание](YOUTUBE.md).

**YouTube: Sign in to confirm your age.** Видео требует аккаунта с подтверждённым возрастом. «Войти в YouTube» → завершите вход/проверку Google → «Я вошёл — подключить» → повторите загрузку с аккаунтом. Если ошибка остаётся, обновите сессию и проверьте, что тот же аккаунт открывает видео в отдельном окне. Ключ Gemini для скачивания не нужен. Техническая причина отказа сохраняется в `.run/server.log`.

**Не удалось прочитать сессию Chrome.** Закройте отдельное окно входа после авторизации и попробуйте подключение снова. При запросе macOS разрешите доступ к Chrome Safe Storage. Если доступ по-прежнему закрыт, используйте импорт youtube.com cookies.txt в формате Netscape. Обычный рабочий профиль Chrome студия не читает.

**Нет субтитров / нет слов.** Рендер с включёнными подписями откажет, если слов нет. Запустите транскрипцию или явно выключите captions. Изменение стиля требует нового рендера; CSS-preview не является готовым файлом. В текущем FFmpeg может отсутствовать libass — есть реальный RGBA fallback с кириллицей.

**Рендер неудачен.** Посмотрите конкретный FFmpeg/QC error в очереди. Auto encoder попробует VideoToolbox и перейдёт на libx264 при несовместимости. Для воспроизводимости можно выбрать Software. Безопасный crop — Blurred Background. Сократите число сегментов при очень длинном плане.

**Clip not found при пакетной генерации.** Исправлена маршрутизация: старый пакетный адрес ошибочно считался запросом к клипу с ID `batch`. Обновите страницу. Используйте Generate Reel в библиотеке. Если выбранный клип удалён в другой вкладке, обновите список и выберите актуальные клипы; пакет проверяется целиком до добавления задач.

**ZIP не скачался сам.** Дождитесь завершения задачи «ZIP с готовыми роликами» и нажмите «Скачать ZIP» в очереди. При ошибке одного рендера сначала исправьте/повторите его, затем повторите ZIP или новую пакетную генерацию. При паузе рендера ZIP ожидает продолжения.

**Удаление заблокировано.** Выбранные клипы ещё участвуют в генерации или ZIP. Завершите либо отмените соответствующие задачи. Исходники не удаляются при удалении клипов, старые ZIP сохраняются.

**Сервер не запускается / браузер показывает Error.** Откройте `start.command` и обновите http://127.0.0.1:8765. После перезагрузки Mac сервер нужно запустить снова. Проверка: `.venv/bin/python scripts/launcher.py status`, `.run/server.log`, `doctor.command`. Запуск работает через launchd: закрытие Terminal не выключает сервер, аварийное завершение вызывает перезапуск. Ошибки до старта Python записываются в `/private/tmp/local.ai-shorts-factory.<идентификатор>.bootstrap.log`. Порт 8765 может быть занят. `stop.command` снимает только службу этого проекта; для старого способа запуска проверяет команду и путь перед остановкой PID. Сервер слушает 127.0.0.1, с телефона в локальной сети недоступен по умолчанию.

**Окружение перенесено.** Пересоздайте `.venv` через setup, сохранив `data` и `database`. Не удаляйте другие пользовательские каталоги. API key снаружи окружения: Settings хранит `.secrets/gemini.key` (0600); переменная `GEMINI_API_KEY` тоже поддерживается. `.env.example` не загружается автоматически.

**После Pause сразу Resume выдаёт сообщение остановки.** Подождите секунду: собственный дочерний процесс должен завершиться перед повторным запуском.
